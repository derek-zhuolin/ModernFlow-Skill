## 它是什么

你给 agent（Claude Code / Codex / Cursor / …）一个主题。它读这个 skill，写一份 spec 说清楚这张图**是什么意思**，然后解算器算出每一个坐标和每一拍。

**spec 里没有任何一个坐标。** 整个设计就是这一句：

| 你改了 | 什么会重算 |
|---|---|
| 一个标签 | 它的盒子宽度、进出它的两条边、箭头角度 |
| 节点顺序 | 节拍表，以及它之后的每一拍 |
| 画幅改成竖版 | 整个版面重解，不是把横版压扁 |
| 旁白语速 | 每一段间隙——时长不动，地板 300ms |
| 强调点 | 谁戴那个圈，以及相机去哪 |

手摆的图，内容一变就错，而且**照样能渲染出来**。这种失败没有任何报错——这就是为什么它是解算器，不是模板。

## 怎么选类型

按主题的形状选，不按好看选。判据是一句你应该能说出口的话：

| 你说的那句话 | 类型 |
|---|---|
| 「有分支的步骤，而且某条路会结束」 | `flow` |
| 「最后一步喂回第一步，中间有东西在累积」 | `loop` |
| 「每一层压在下一层上」 | `layers` |
| 「一个爹很多儿子——是包含，不是流动」 | `tree` |
| 「两个轴上打分，位置**就是**主张」 | `quadrant` |
| 「按日历排的活，重叠才是重点」 | `gantt` |
| 「几个集合有共同成员」 | `venn` |
| 「我要人记住一个数」 | `stat-row` |

41 种类型，7 种几何。**其中 8 种有自己的解算器**——`timeline` / `sequence` / `swimlane` / `gantt` / `radar` / `treemap` / `mindmap` / `er`——因为用族的通用几何画出来会说假话。条长全一样的甘特图，已经把它要展示的排期冲突弄丢了。

判据不是「看起来不一样」，是「用通用版本会不会说出假话」。

## 三层产物，一张节拍表

| 你要的 | 层 | 需要 | 产出 |
|---|---|---|---|
| 「给我张图」 | **still** | 浏览器 | `.html` + `.png` |
| 「让它动起来」 | **motion** | 浏览器 | 一个自播的 `.html` |
| 「做成视频」 | **video** | HyperFrames | `.mp4` |

still 和 motion 是**同一个文件**——动效是纯 CSS，静帧就是这个文件在某一刻的截图。**HyperFrames 只有 MP4 那一层要用。** 其余全部只要 Python 和浏览器。

任何一页都能定帧：URL 后面加 `?t=4.4`，或者控制台里 `mfSeek(4.4)`。`build.py --png --at 4.4` 走的是同一条路——所以静帧是可复现的，而不是取决于机器多快跑到第 4 秒。

## 相机

动效动的是元素，相机动的是画框。把两者搅在一起是最常见的错误——放大你想让人看的节点，说的是**那个节点变大了**，不是**你走近了**，而且把 zoom 焊死在那个节点的入场上，之后永远不能重剪。

一次运镜是一对 `push` / `pull`，它们是同一 origin 上的精确逆变换，所以任意时长的驻留都不需要 JS、不需要 keyframe 百分比。`camera: "auto"` 是默认值，从同一个种子骰子里选形态——`punch` / `survey` / `drift` / 不推——并且**少于 4 个节点一律不推**，骰子说什么都不推。三个节点的图上没有东西可去读，没有指涉的运镜就是换了身衣服的空转。

## 变化

八场用同一种方式做出来，看起来就是同一场的八遍。**按索引轮换**比不轮换更糟：索引 0 永远是同一个手势，所以任何人做的任何一套图，节奏永远是同一套。

入场和转场改由**种子排列**决定——同一份 spec 永远出同一支片，因为「重渲一次悄悄变成另一个剪辑」会让按上一版对好的旁白全部错位。骰子带约束：相邻的缝不能重样，而且种类数要够 ⌈缝数/2⌉——光「不相邻重复」不够，`A B A B` 完全满足，但永远只用两种。

## 安装

```bash
git clone https://github.com/derek-zhuolin/ModernFlow-Skill ~/.claude/skills/modernflow
python3 ~/.claude/skills/modernflow/scripts/doctor.py
```

**Python 3.9+，除此之外什么都不要。** 没有 pip、没有 npm、没有 lockfile——每个脚本都只用标准库。Chrome 只在把图栅格化成 PNG 时需要；没有它你照样拿到 HTML，脚本会明说。

clone 到了别处，或者同时装了好几个 agent？`python3 scripts/install.py` 会探测 Claude Code / Codex / Cursor / Gemini CLI / Crush / OpenCode，装进每一个找得到的。

**换台电脑出的图一模一样。** 字体包是提交进仓库的——16 个子集化字面，覆盖两套 profile，约 1.2MB——所以新 clone 离线也能渲，而且渲出来一样。缺字形**不会报错**：浏览器会拿一个系统字体顶上，那个字体通常在做图那台机器上有，在别人机器上没有。`scripts/check_fonts.py` 专门守这一条。

## 质量闸

每一条都会以非零码退出，每一条守的都是**照样能渲染、但是错的**那类问题：

- **预算** —— 单图超过 9 节点 / 12 条边 / 1 个强调；边指向不存在的节点；判定节点的出边没标签；相机移动重叠。在写出第一个字节之前就查。
- **对比度** —— 每个文字角色对上它可能落在的每一种背景，按渲染后的字号，过 WCAG AA。定义这套观感的那个浅灰标签，压在色场上只有约 2.1:1，肉眼看不出来。
- **字形覆盖** —— 页面上每一个字都在字体包里。
- **确定性** —— `doctor.py` 把 gallery 解两遍，比哈希。
- **看一眼** —— `scripts/playground.py spec.json -o out.html` 把每一场放进同一页、带滑杆。第七道闸只有便宜了才是真的存在。
